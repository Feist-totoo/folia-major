# Folium 独立调试器

调试器直接读取标准 Folium 模组目录。创建和检查仍使用仓库已有工具，播放器加载、信任确认、重载和卸载仍使用桌面版 Folium。

```sh
npm run folium:new -- my-visualizer
npm run folium:studio -- mods/my-visualizer
```

终端会显示仅限本机的随机会话 URL 并打开浏览器；`--no-open` 只输出 URL。关闭终端停止服务。修改模组源码后点击“重载源码”，旧 iframe 与其资源一起销毁。

支持标准 `client.mjs` 和相对 JS 模块、`registries.visualizers`、主题字体帮助函数、歌曲与歌词时钟、生命周期和默认设置。调试上下文直接复用播放器的生命周期、参数校验和歌词时序提示代码；音频能量为模拟数据。含 main、依赖、权限或实验接口的模组会被拒绝，其他未模拟的 API 会明确报错。这里不提供宿主字幕叠层、持久化或真实音频分析。

可测试横竖屏、长句、多语言、纯音乐、字号、主题、隐藏歌词、静态预览、暂停和任意 seek；也可导入最多 1 MiB 的 `FoliumLine[]` JSON。设置 JSON 经过原参数规则处理。画布可导出 PNG；DOM 模组使用浏览器截图。报告包含输入和日志，`accepted` 始终为 false，不能用静态检查或截图代替视觉验收。

视频参考仅在浏览器本机解码：最多 250 MiB，每次选取不超过 60 秒、最多 12 帧，记录时间点、观察和参考图，导出 ZIP 交给 Agent 分析。该功能不自动恢复原视频的代码、资产或动画曲线。

预览运行在无同源权限的 iframe 中，服务只读取明确选定的目录，阻止路径越界，限制单文件大小和模块导入；这不是对任意恶意程序的完整安全承诺。只预览自己信任的代码。最终必须在真实桌面 Folia 中安装、确认启用，验收切歌、设置、暂停/seek 和停用后的资源释放。成品按官方 Folium 模组贡献规范发布。
